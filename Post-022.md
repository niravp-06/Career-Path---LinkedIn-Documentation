## Commands Covered

### which
Locates the full path of an executable file associated
with a specific command.

### bc (Basic Calculator)
Opens a calculator terminal interface for basic
calculations directly inside the terminal.

### cal (Calendar)
Prints a full year or month-year calendar in the terminal.
Any year or month-year combination can be printed.

### uptime (Server Users)
Shows how many users are using the system/server —
prints user info along with connected timestamp.

### script
Records every command practiced in a session.
All typed commands get saved into a new file called
`typescript`, accessible directly through `cat`.

### alias
Creates custom shortcuts for specific commands.
⚠️ **Note:** The shortcut remains only while the terminal
session is active — auto-deleted after closing the terminal.

### Compression & Decompression
Files and folders can be zipped or unzipped directly
through the terminal.
