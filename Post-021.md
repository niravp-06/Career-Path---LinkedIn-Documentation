## Commands Covered

### Split Command
- Used for splitting file contents into parts
- Flags used: `-l`, `-b`, `-n`, `-d`

### Grep Command
- Used for finding words in a file using `grep`
- `egrep` — for finding multiple words at once using `|`

### Wild Cards
`[ ]`, `{ }`, `*`

### Shuffle Command
Used for shuffling file contents of a file.

### Compare Command
- Used to compare files
- Shows only whether files are same or not

### Difference Command
Using `diff` command, user can find more detailed
differences between compared files.

### Find Command
Used to find files in a specific path by name.

### Locate Command
- Also used to find files, but works instantly through
  its system database cache
- Needs `sudo updatedb` to update the cache if new files
  are added into the system
